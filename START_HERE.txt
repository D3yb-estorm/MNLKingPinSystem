## 🚀 How to Use

### Starting the Application
1. Open `index.html` in any web browser
2. Login with any username/password
3. Choose role: "Customer" or "Admin"
4. Start using!

### As a Customer
1. Browse products
2. Add items to cart
3. Enter measurements for sizing advice
4. Complete checkout
5. Track your order progress
6. View order history

### As an Admin
1. Manage products (add/edit/delete)
2. View and process all orders
3. Update order status and send notifications
4. View complete customer database
5. Access purchase history with search
6. Generate sales reports
7. Export data to CSV

---

## 💾 Data Storage

All data is automatically saved to browser storage (localStorage):
- **Purchase History**: Permanent record of all orders
- **Customer Database**: Profiles auto-created on first purchase
- **Notifications**: All status updates logged
- **Preferences**: Customer preferences and measurements

**Important**: Data persists across sessions and browser restarts!
